# Experimental scalar math supplement

`python3 ports/srvros/libm/build.py` builds `build/browser-libm/libsrvros-jsc-math.a` and `libmprobe.elf` against the matched SrvrOS SDK and Zig 0.15.2. It uses the pinned Zig distribution's musl sources under `lib/libc/musl/src/math`, its internal `libm.h`, generic `fp_arch.h`, and x86_64 SSE `sqrt` sources. `build.py` lists the exact source and table files, compiler commands and input hashes in `build/browser-libm/receipt.json`; it invokes `host_test.py`, which records a separate receipt and logs. The archive provides the 17 functions listed as `public_symbols` in that receipt. It does not replace the SDK's public `exp`, `log`, `sqrt`, `tanhf`, or `expm1f`.

The supplement compiles its own accurate `exp`, `expf`, `log`, `logf`, `sqrt`, `sqrtf`, and `expm1f` dependencies with `srv_libm_private_` names, along with prefixed data tables and error helpers. It uses local x86_64 type/endian adaptations in `compat.h` and `endian.h`, without changing the upstream algorithm sources. `domain.c` adds one documented guard: `acosh` and `acoshf` reject inputs below one through the real musl invalid-operation helper before calling the pinned implementation. This avoids an observed large-negative cancellation case that could otherwise yield a finite value. It does not implement an errno policy or add an exception runtime.

The host comparison builds renamed copies of the same source closure and compares against the host libm. The retained host receipt `build/browser-libm/host-34y2a43j/receipt.json` records passing edge, domain, threshold-neighbor and 10,000 deterministic binary64-pattern cases with an eight-ULP bound. The independent archive inspection found no undefined reference left after subtracting definitions provided within the supplement. In the matched 15-case Q35/TCG run `build/browser-runtime/guest-9cufz_rw/receipt.json`, the target probe passed its signed-zero, subnormal, domain, nonfinite and representative finite vectors. These bounded checks do not establish full IEEE rounding-mode, floating-point exception, errno, or general SDK math conformance, nor do they qualify every input. Guest results apply to the recorded artifacts and configuration.
